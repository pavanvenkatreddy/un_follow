Follow Check Privacy Policy

Effective date: October 3, 2026

Follow Check is a local-only Chrome extension for comparing the Instagram followers and following lists available through the Instagram session already open in your browser.

Data the Extension Handles

Follow Check may process your Instagram account id and username, Instagram follower and following account data returned by Instagram while you run a scan, comparison results, and local cache data used to avoid repeatedly fetching the same network comparison lists.

How Data Is Used

The extension uses this data only to run follower/following comparisons, display results in the extension, export local CSV files when you choose to export, and cache selected network comparison data locally.

Follow Check does not use this data for advertising, profiling, resale, or unrelated purposes.

Storage and Retention

Follow Check stores scan results and network cache data in chrome.storage.local on your device. This data is not uploaded to a server controlled by the extension developer.

You can delete locally stored extension data by removing the extension from Chrome, clearing extension storage through Chrome settings, or using the extension's Clear Cache button for network comparison cache data.

Data Sharing

Follow Check does not sell, transfer, or share follower data with third parties. The extension communicates with Instagram because it must request follower/following pages from Instagram to perform its stated function.

Security

Requests to Instagram are made over HTTPS using your existing browser session. Follow Check does not ask for, collect, or store your Instagram password.

User Control

You control when scans run. The extension does not automatically scan in the background. CSV exports are created only when you choose to export them.

Limited Use Statement

Follow Check's use of information received from Chrome APIs and Instagram responses is limited to the extension's single purpose: local follower and following comparison. The extension's use of user data complies with the Chrome Web Store User Data Policy, including limited-use requirements.

Changes

This policy may be updated as the extension changes. The effective date above will be updated when material changes are made.
